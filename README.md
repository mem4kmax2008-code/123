# StudentApp - Практическая работа № 1

## Описание
Приложение для работы с базой данных студентов на Python с использованием SQLAlchemy ORM и Tkinter GUI.

Это реализация паттерна "Модуль данных" (Data Module), который позволяет централизовать всю работу с базой данных и отделить логику данных от интерфейса пользователя.

## Требования
- Python 3.7+
- SQLAlchemy
- Tkinter (обычно встроен в Python)

## Установка

```bash
pip install -r requirements.txt
```

## Функционал

### Операции с данными
- ✅ **Добавить** - добавление нового студента
- ✅ **Редактировать** - изменение данных студента (двойной клик или кнопка)
- ✅ **Удалить** - удаление студента с подтверждением
- ✅ **Обновить** - обновление таблицы
- ✅ **Поиск** - поиск по имени в реальном времени

### Интерфейс
- Главное меню (Файл, Справка)
- Панель инструментов с кнопками
- Панель поиска
- Таблица с полосами прокрутки
- Строка состояния

## Ключевые концепции

### ORM (Object-Relational Mapping)
Технология, позволяющая работать с БД через объекты Python вместо SQL-запросов.

### Модель данных (models.py)
```python
class Student(Base):
    __tablename__ = 'students'
    id = Column(Integer, primary_key=True)
    full_name = Column(String(100), nullable=False)
    birth_year = Column(Integer)
    group_name = Column(String(20))
```

### Модуль данных (data_module.py)
Класс `DataModule` инкапсулирует:
- Подключение к БД
- Управление сессиями
- CRUD операции
- Поиск и фильтрацию

### Главное окно (main.py)
Класс `MainWindow` управляет:
- Пользовательским интерфейсом
- Взаимодействием с модулем данных
- Валидацией данных
- Обработкой ошибок

## Методы DataModule

| Метод | Описание |
|-------|----------|
| `open()` | Открыть сессию для работы |
| `close()` | Закрыть сессию |
| `get_all_students()` | Получить всех студентов |
| `get_student_by_id(id)` | Получить студента по ID |
| `add_student(...)` | Добавить нового студента |
| `update_student(id, ...)` | Обновить данные студента |
| `delete_student(id)` | Удалить студента |
| `find_students_by_name(name)` | Поиск по имени |
| `get_students_by_group(group)` | Получить студентов группы |
| `get_students_count()` | Количество студентов |

## Примеры использования

### Добавление студента
```python
data_module = DataModule()
data_module.open()
student = data_module.add_student(
    full_name="Иван Петров",
    birth_year=2005,
    group_name="ПИ-21"
)
```

### Поиск студентов
```python
students = data_module.find_students_by_name("Петров")
```

### Получение студентов группы
```python
group_students = data_module.get_students_by_group("ПИ-21")
```

## Валидация данных

- ФИО - обязательное поле
- Год рождения - должен быть числом
- Группа - необязательное поле

## Обработка ошибок

Все операции с БД обработаны try-except блоками с информативными сообщениями пользователю.

## Особенности реализации

1. **Паттерн Repository** - `DataModule` реализует паттерн репозитория для работы с БД
2. **Модальные диалоги** - окна добавления/редактирования блокируют основное окно
3. **Состояние интерфейса** - кнопки меняют состояние в зависимости от открытия таблицы
4. **Управление сессиями** - автоматическое переиспользование одной сессии для производительности
5. **Безопасность** - защита от SQL-injection благодаря ORM

## Аналогия с Delphi/BDE

| Delphi/BDE | Python/SQLAlchemy |

| TTable | DataModule |

| DBGrid | ttk.Treeview |

| Table.Open | DataModule.open() |
| Table.Close | DataModule.close() |
